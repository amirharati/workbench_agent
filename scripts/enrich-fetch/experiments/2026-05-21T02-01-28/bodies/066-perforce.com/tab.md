### What Is the Difference Between VR and AR? MR and XR?

What's the difference between VR, AR, MR, and XR?

Virtual reality (VR) transports the person into new, highly interactive environments, often using VR goggles. The goal is shut out the physical space and make the user feel like they are part of a new digital world — real or imaginary.

Augmented reality (AR) adds digital elements into the real world. Remember the Pokémon Go phenomenon? People were able to travel around physically to collect virtual creatures. Mixed reality (MR) combines aspects of both AR and VR to have real-world and digital objects overlay and interact.

All three of these terms are classified under the umbrella term, extended reality (XR). This includes technologies that enhance all the senses.

## How Virtual Reality Software Works

Virtual reality technology creates a new world by:

*   Developing objects that exist in a virtual 3D space, which helps to create robust VR scenes. 
*   Adding in sensory feedback to give a sense of presence — for example, sound or haptic feedback.
*   Emerging the user in interactive elements.

VR software development tools work based on the level of immersion they provide. Most VR technology can be categorized in terms of software development kits (SDKs), build tools (like game engines), and content creation/management.

### Software Development Kits (SDKs)

A software development kit (SDK) includes a set of software tools and programs used for multiple platforms. It can include libraries, samples, process, guides, tutorials, blueprints and more.

For VR software development, the VR SDK you select determines the hardware your users will need. It is important to research options and determine the best fit for your product. Some of the most popular SDKs for VR software development include:

#### _HTC Vive_

[OpenVR SDK](https://github.com/ValveSoftware/openvr "(opens in a new window)") is an open VR software development kit (SDK) and API that supports HTC Vive and other VR headset related devices. [SteamVR SDK](https://developer.valvesoftware.com/wiki/SteamVR "(opens in a new window)") and [VRTK](https://vrtoolkit.readme.io/ "(opens in a new window)") (Virtual Reality Tool Kit) are also used for HTC Vive. These offer additional benefits like access to controllers, chaperoning, models, and preview in Unity play mode.

#### _Sony Playstation_

To develop for the Sony PlayStationVR, you need to have [PSVR Dev Kit](https://www.playstation.com/en-gb/explore/playstation-vr/ "(opens in a new window)") and to become a registered developer. Features of this VR SDK include 360-degree vision, incredible visuals/audio, and enhanced tracking.

#### _Oculus/Samsung_

Considered the best SDK for Oculus Rift, [Oculus SDK](https://developer.oculus.com/downloads/ "(opens in a new window)") comes with game engine specific kits. It also includes sample assets, audio packages, and more. There are also supporting SDKs for Windows and Oculus Mobile. The [Oculus Mobile SDK](https://developer.oculus.com/downloads/package/oculus-mobile-sdk/ "(opens in a new window)") has been used for the Samsung GearVR and includes tools and libraries for C/C++.

#### _Cross Platform SDKs_

[Google VR SDK](https://developers.google.com/vr/develop/unity/get-started-android "(opens in a new window)") is meant to work with the Google cardboard VR headset. But it offers a wide range of development tools that you can use to create VR applications. [Amazon Sumerian](https://aws.amazon.com/sumerian/ "(opens in a new window)") works with popular VR platforms like Oculus Go/ Rift, HTC Vive/Vive Pro, Google Daydream, and Lenovo Mirage. It also is compatible across Android and iOS mobile devices as well.
