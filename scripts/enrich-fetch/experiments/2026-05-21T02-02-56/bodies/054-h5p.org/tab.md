Develop new content types  
If you are a developer familiar with JavaScript and other related web technologies, we suggest you do the following:

1.  Install a CMS and an H5P plugin for that CMS. Currently, the easiest way is to download [Drupal](https://drupal.org/project/drupal) and the [H5P Drupal plugin](https://drupal.org/project/h5p). The Drupal plugin has some extra development features that the other plugins don't have.
2.  Complete our ["Hello world tutorial](https://h5p.org/tutorial-greeting-card)"
3.  Look at the [H5P examples](https://h5p.org/content-types-and-applications)
4.  Get familiar with the [developer guide](https://h5p.org/developers)
5.  Create new libraries using your newly acquired H5P skills
6.  [Share](https://h5p.org/getting-involved) your work here at H5P.org!

![](https://h5p.org/sites/default/files/coding.png)

Improve existing H5P content types  
The code for the H5P content types are shared on [GitHub](https://github.com/h5p).

Designers and developers are encouraged to improve these content types by:

1.  Setting up your H5P development environment using the [installation and setup guide](https://h5p.org/installation).
2.  Downloading H5P libraries from the [examples and download page](https://h5p.org/content-types-and-applications) or our [GitHub](https://github.com/h5p) repository.
3.  Extending or modifying the library.
4.  Sharing your improvements on our [forum](https://h5p.org/forum/2) and submitting a [pull request](https://help.github.com/articles/using-pull-requests/) on GitHub!
