Fancy a specialized dataclass to carry and manipulate tensors? We've opensourced a new [PyTorch](https://www.linkedin.com/company/pytorch?trk=public_post-text) tool under the [#tensordict](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Ftensordict&trk=public_post-text) repo: tensorclass In a few words, tensorclass is a dataclass that allows you to use dedicated tensor methods over all the tensors you're carrying. You can index, reshape, mask, stack and apply many more functions to your data in just a few characters. With our memory-mapped tensors, tensorclass allows you to access datasets on disk through contiguous tensors which significantly speeds up training time (see the comments for an example). @tensorclass is available today on our PyPI release, simply $ pip install tensordict and you're good to go! -> Follow us on [https://lnkd.in/eHM5xWca](https://lnkd.in/eHM5xWca?trk=public_post-text) -> Check out tensorclass and tensordict on [https://lnkd.in/e\_eQRWpc](https://lnkd.in/e_eQRWpc?trk=public_post-text) -> See the doc here: [https://lnkd.in/eb2YwrNA](https://lnkd.in/eb2YwrNA?trk=public_post-text) -> Check TorchRL on [https://lnkd.in/eKeutfrK](https://lnkd.in/eKeutfrK?trk=public_post-text) [#machinelearning](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Fmachinelearning&trk=public_post-text) [#pythonprogramming](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Fpythonprogramming&trk=public_post-text) [#pythondeveloper](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Fpythondeveloper&trk=public_post-text) [#ai](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Fai&trk=public_post-text) [#pytorch](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Fpytorch&trk=public_post-text) [#engineering](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Fengineering&trk=public_post-text) [#datasets](https://www.linkedin.com/signup/cold-join?session_redirect=https%3A%2F%2Fwww.linkedin.com%2Ffeed%2Fhashtag%2Fdatasets&trk=public_post-text)
