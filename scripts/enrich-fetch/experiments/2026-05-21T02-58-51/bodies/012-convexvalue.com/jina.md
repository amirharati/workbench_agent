## Docs

Welcome to ConvexValue.

The ConvexValue Terminal is a desktop app. It is like a web-browser (Chrome, Safari, etc.) but instead of browsing the internet, you browse a curated selection of financial analytics modules.

It allows you to create and save split-pane dashboards. You can also share them with others and clone dashboards others have published.

The following guide covers how to operate The ConvexValue Terminal.

You can also build your own ConvexValue apps with the scaffold tool and Codex:

```
npm create convexvalue@latest my-app
cd my-app
cvx login
npm run dev:cvx
codex
```

It is also available as a [long-form video crash course](https://youtu.be/uGe5wL8lTp0), and as a [3-minute flash tutorial](https://youtu.be/KGh1Ifp9d0Q).
